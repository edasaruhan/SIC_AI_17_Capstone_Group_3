# Generated artifacts

This directory is intentionally ignored except for documentation and placeholder files.
Every CSV, JSON, and PNG below it must be regenerated by code. The quick pipeline writes
to `artifacts/quick/`; the streaming full-source audit writes to
`artifacts/full/raw_data_audit.json`.

Artifact manifests state whether their source is the real IBM AML HI-Small data or an
explicit synthetic fixture. Never compare or relabel synthetic fixture output as an IBM
dataset result.
