# ARGUS tracked product demo

`artifacts/dashboard_bundle.json` is a small, deterministic product walkthrough bundled with
the repository so a clean clone can open the analyst workspace without the private local
artifact package.

Every account, transfer, case, score, contribution, and narrative in this directory is
illustrative synthetic fixture data. It is not copied from IBM AML HI-Small, is not produced by
the frozen ARGUS models, and must not be reported as project evaluation evidence. The published
scientific results remain in `reports/generated/` and require the separately retained frozen
artifact package for machine-readable verification.

The model-comparison rows are clearly labelled display references copied from the published
validation reports. Those reports remain authoritative; this demo bundle is not a
machine-readable scientific evidence package.

Set `ARGUS_ARTIFACT_DIR` to a verified Sprint 5 package to replace this fallback locally.
