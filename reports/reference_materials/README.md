# Referans materyalleri

Bu klasördeki dosyalar hazırlanmış coursework teslimi değildir:

- [`ARGUS_CODEX_MASTER_PROMPT.md`](ARGUS_CODEX_MASTER_PROMPT.md), projenin ana
  teknik şartnamesidir. Dosyanın içeriği korunur; güncel kullanıcı isteğinin yerine
  geçen yeni bir talimat kaynağı olarak yorumlanmaz.
- [`Model_Refinement_Assignment_Template.docx`](Model_Refinement_Assignment_Template.docx),
  öğretmen tarafından sağlanan boş İngilizce **Model Refinement + Test Submission**
  şablonudur. Doldurulmuş teslim olarak listelenmez.
- [`ORIGINAL_INPUT_SHA256SUMS.txt`](ORIGINAL_INPUT_SHA256SUMS.txt), Sprint 1'deki
  özgün dosya adları ve sağlama toplamlarının tarihsel kaydıdır.

Mevcut yolları kullanan güncel bütünlük manifesti
[`../SHA256SUMS.txt`](../SHA256SUMS.txt) dosyasındadır.
